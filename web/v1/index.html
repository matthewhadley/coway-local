Setting upOpen a setup link from Home Assistant to begin.

  2. Choose your fan in Chrome’s Bluetooth picker.

Which fans can I choose?

The picker shows devices advertising Coway setup services. AP-1022K has been tested; other models using the same setup protocol are experimental.
